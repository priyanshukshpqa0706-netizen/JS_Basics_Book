# JS_Basics_Book
This repo will give you more clarity about JS concepts


1) JS Basics :
a)Keywords: it is a reserved words used in the particular prog lang.
Ex: var, let, const, void, async, true, false, null, undefined etc.

b)Identifiers/Variable Name: It is a name given to the variable.

c) Operator: It works with the operands to perform any task/operation.

d)Literals: it is the value assigned to the variable name.


  let x = 10;
  where let: Keywords
		Identifiers/Variable Name: x
		10: Literals
		= : Operator
		
2) var, let and const

  const: it has a fixed value, once the value is assigned, we cannot change.
